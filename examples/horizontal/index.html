← Veyra examples05 · horizontal sections

Scroll down, travel sideways.

horizontal() pins a section with CSS sticky and turns vertical scrolling into horizontal travel, sizing the section so both distances match. In a right-to-left section the row travels rightward, so panels still arrive in reading order. It settles on the nearest panel when scrolling stops, writes each panel's progress to --panel-progress, and keyboard focus inside an offscreen panel scrolls the page to it.
